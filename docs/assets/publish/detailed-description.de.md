Wir richten deine mittwald-Domain als Pull Zone bei bunny.net ein, konfigurieren die DNS-Einträge und aktivieren das CDN – dein Web-Traffic wird sofort über das bunny.net-Netzwerk beschleunigt.

bunny.net ist ein EU-basierter CDN-Anbieter mit Sitz in Slowenien. Das bedeutet: volle DSGVO-Konformität ohne US-Cloud-Act-Risiko. Dazu bietet bunny.net globales Edge-Caching an über 120 PoPs, DDoS-Schutz, kostenlose SSL-Zertifikate und eine leistungsstarke Edge-Rules-Engine.

## Wie funktioniert es?

Wir übernehmen für dich:

- Erstellen einer Pull Zone für deine mStudio-Domain bei bunny.net.
- Konfiguration der DNS-Einträge, damit dein Projekt ohne Downtime sofort über das CDN erreichbar ist.
- Optionale TYPO3-spezifische Edge Rules, damit eingeloggte Frontend-User den Cache umgehen.
- Übersichtliches Dashboard mit Echtzeit-Statistiken zu Traffic, Cache-Hit-Rate und Bandbreite.

Deine Domain wird weiterhin von mittwald verwaltet. Falls etwas nicht passt, kannst du die CDN-Integration mit einem Klick rückgängig machen.

## Einschränkungen

- Ein bunny.net API-Key wird benötigt (kostenlose Registrierung auf bunny.net).
