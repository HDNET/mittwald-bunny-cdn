# Screenshots-Platzhalter

> Dieses Markdown-File ist ein Platzhalter. Ersetze es durch die echten
> Screenshot-Dateien (PNG/JPG) im selben Ordner.

## Spec

| Feld | Wert |
|---|---|
| **Anzahl** | 3–5 Screenshots |
| **Formate** | PNG oder JPG |
| **Größe** | mind. 1280 × 800 px, 16:10- oder 16:9-Verhältnis |
| **Max. Dateigröße pro Bild** | 2 MB |
| **Sprache** | Deutsch (primär), englische Variante optional |
| **mStudio-Feld** | `assets` |

## Empfohlene Motive

1. **`01-wizard-step1-domain.png`** — Setup-Wizard, Schritt 1: Domain
   auswählen. Zeigt den klar strukturierten Setup-Flow.
2. **`02-dashboard-analytics.png`** — Dashboard „Analytics"-Tab mit
   Bandwidth-/Request-Charts, Cache-Hit-Rate, Top-Ländern und den drei
   Health-Badges (SSL / DNS / Origin) grün.
3. **`03-dashboard-performance.png`** — „Performance"-Tab mit aktiven
   Optimizer-Toggles (WebP, AVIF, CSS/JS-Minify) und den TTL-Slidern.
4. **`04-dashboard-security.png`** — „Sicherheit"-Tab mit aktivem
   EU-only-Mode und gepflegter Referrer-Whitelist.
5. **`05-wizard-step4-hints.png`** (optional) — Abschluss-Screen mit DNS-
   und TypoScript-Hinweisen.

## Upload-Schritte

1. Screenshots in diesem Ordner ablegen (`docs/assets/publish/01-...png` usw.).
2. Dieses Platzhalter-File löschen.
3. In mStudio-Publisher hochladen, Reihenfolge wie oben.
