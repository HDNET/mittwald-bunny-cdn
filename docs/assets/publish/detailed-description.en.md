We set up your mittwald domain as a pull zone on bunny.net, configure the DNS records, and activate the CDN — your web traffic is instantly accelerated through the bunny.net network.

bunny.net is an EU-based CDN provider headquartered in Slovenia. That means: full GDPR compliance without US Cloud Act exposure. On top, bunny.net offers global edge caching at 120+ PoPs, DDoS protection, free SSL certificates, and a powerful edge rules engine.

## How does it work?

We take care of:

- Creating a pull zone for your mStudio domain on bunny.net.
- Configuring the DNS records so your project is reachable via the CDN without downtime.
- Optional TYPO3-specific edge rules so logged-in frontend users bypass the cache.
- A clear dashboard with real-time statistics for traffic, cache hit rate, and bandwidth.

Your domain stays managed by mittwald. If something doesn't fit, you can revert the CDN integration with a single click.

## Limitations

- A bunny.net API key is required (free signup at bunny.net).
